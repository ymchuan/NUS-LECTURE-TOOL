# NUS 课堂同传 v0.3.0

## 新增

- 使用 `gpt-5.4-mini` 生成结构化阶段总结。
- 自动识别主题转场，也可点击“立即总结”。
- 结束课堂时生成整课总结，并利用阶段总结保留长课堂上下文。
- 知识点、课堂依据、定义、例子、考试提示和复习问题归纳。
- 思维导图详情视图，支持桌面与窄屏布局。
- 可选 OpenAI Web Search 相关拓展，展示可点击参考来源。
- 总结内容和来源随课堂记录写入 SQLite，可在异常恢复后继续查看。

## 使用

1. 在“课程与术语”中保存 OpenAI API Key。
2. 在“智能总结”中选择是否自动总结、是否联网拓展。
3. 开始听课；主题结束后会自动生成阶段总结，也可手动触发。
4. 点击阶段总结右上角的展开按钮，查看知识归纳、思维导图和相关拓展。
5. 点击“结束”后等待整课总结完成。

## 模型

- 实时英文转写：`gpt-live-transcribe`
- 中文翻译：`gpt-5.4-nano`
- 阶段与整课总结：`gpt-5.4-mini`
