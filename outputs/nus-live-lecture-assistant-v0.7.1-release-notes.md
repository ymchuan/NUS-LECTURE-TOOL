# NUS 课堂同传 v0.7.1

## 翻译连接修复

- 修复阿里云共享入口短暂拒绝连接后，翻译一直没有结果的问题。
- 翻译请求最多同时运行两条，避免多个 ASR 语段完成时集中建立 HTTPS 连接。
- 网络错误按 200 ms、600 ms、1.5 秒、3 秒递增重试四次。
- 每次重试都会重新解析 DNS 并建立新连接，不复用可能失效的连接状态。

## 专属新加坡线路

- 设置中新增“阿里云业务空间 ID”，接受 `llm-` 开头的 ID。
- 填写后，实时 ASR、翻译与总结会统一使用 `{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com`。
- 未填写时仍兼容原有 `dashscope-intl.aliyuncs.com` 共享域名。

业务空间 ID 不是 API Key，可在阿里云百炼新加坡地域的“业务空间管理”页面复制 API Host，并取其中 `llm-...` 部分。
