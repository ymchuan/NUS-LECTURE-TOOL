# NUS 课堂同传 v0.12.8

## 本次更新

- 修复实时记录自动滚动：只有用户停留在列表底部时才跟随新内容，向上回顾时不再被强制拉回。
- 修复结束课堂时末尾转写或翻译丢失：结束前会冲刷语音缓冲并等待正在进行的翻译，失败时保留英文原文。
- 清理旧版本遗留的临时转写，并修复历史课堂中永久停留在“正在翻译”的记录。
- 优化实时翻译：只发送与当前句子最相关的课程术语，减少请求体积、延迟和模型用量。
- 修复阿里云流式翻译分包导致的中文乱码，并改善超时、网络错误和服务端错误提示。
- AI 问答改为原子保存：失败请求不再留下空白问题或幽灵会话；切换课堂或资料范围时也不会串入旧回答。
- AI 回答只显示真实存在的课堂、课件和 syllabus 引用；历史回答中模型虚构的引用标记会自动隐藏。
- Markdown、列表和 LaTeX 公式使用专用渲染，`$`、`**`、反斜杠等原始格式不再直接暴露给用户。
- 阶段总结继续面向课堂即时回顾；整课总结使用更大的详细结构，覆盖定义、知识点、例题、复习提示和思维导图。
- 相关知识拓展要求给出具体解释、公式、变量、使用步骤、例题及可核验来源，不再只列知识点名称。
- 修复结构化总结中控制字符导致的 JSON 解析失败，并限制模型返回的来源只能来自实际联网检索结果。
- 提升课件页面匹配：更重视最近三句讲解，限制无依据的向前跳页，只有老师明确提到返回页面时才允许自动回退。
- PDF 直接展示原始页面；PPTX 预览失败会正确释放资源，避免长时间使用后的内存增长。
- 强化课件导入、删除和备份恢复校验，限制异常压缩包，验证数据库完整性，并支持 macOS 与 Windows 间迁移课件路径。
- 修复课堂切换、历史课堂返回、书签失败提示、备份恢复和课程数据归属等边界问题。

## 说明

- 安装包不会包含本机 Keychain 中保存的 OpenAI 或阿里云 API Key。
- 旧总结不会被后台自动改写；需要打开旧整课总结并点击“重新生成”，才能得到新版的详细拓展结构。
- 本轮未主动调用付费模型或录制麦克风，避免产生费用和上传课堂内容；云端连通性仍取决于本机网络、API 权限和账户额度。
