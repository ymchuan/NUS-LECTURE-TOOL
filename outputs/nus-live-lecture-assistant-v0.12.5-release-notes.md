# NUS 课堂同传 v0.12.5

## 本次改进

- “相关知识拓展”不再只列出学习方向，而是直接提供可用于学习和复习的具体内容。
- 每项拓展包含与课堂内容的关联、原理说明、关键结论和实际应用步骤。
- 公式类主题会给出完整表达式、变量及单位、适用条件、使用步骤和带数值代入的算例。
- 每项拓展附带 1-3 个本次联网检索得到的权威来源，链接可直接打开核对。
- 应用会过滤无效和重复链接，并将未归入具体知识条目的检索结果单独列为“其他检索来源”。
- Markdown 课程导出同步保留拓展说明、公式、算例和来源链接。
- 旧版总结保持兼容；旧条目可继续查看，重新生成整课总结后会使用新版详细结构。

## 使用提示

1. 在设置中开启总结的联网搜索选项。
2. 新生成阶段总结或整课总结后，打开“拓展与来源”页查看详细内容。
3. 已保存的旧总结不会自动产生额外模型费用；需要时在历史课堂中点击“重新生成”。

详细拓展会增加总结模型的输出量和 Web Search 使用量，因此相较旧版会有一定额外费用。
