# NUS 课堂同传 v0.12.3

## Slides 自动匹配

- 重写页面匹配算法，降低口语填充词、常见词和重复标题造成的误匹配。
- 根据当前页、相邻页和老师的翻页提示判断页面切换，阻止无依据的跨章节跳页与自动倒退。
- 连续多次确认后才切换页面；证据不足时保留当前页，不再强行显示一个错误结果。
- 使用真实课堂的 134 分钟转写和 68 页 Slides 完成回放验证。

## 手动校正

- Slides 查看器新增上一页、下一页和页码输入。
- 可将正在查看的页面设为当前页，之后的自动匹配会从该页继续判断。
- 有 Slides 但尚未形成可靠自动匹配时，也可以直接打开 Slides 查看器。
