# NUS 课堂同传 v0.12.11

## 本次修复

- 修复阶段总结返回未闭合 JSON 数组时出现 `EOF while parsing a list` 并直接失败的问题。
- 联网搜索产生多个消息块时，优先读取最后一个最终消息，不再误取中间输出。
- 检测模型的 `incomplete` 状态和 JSON EOF 截断。
- 首次解析失败后自动进行一次精简重试：提高输出空间、关闭本次联网拓展，并优先生成完整课堂核心总结。
- 若自动重试仍失败，错误信息会明确区分首次截断与二次解析失败，便于继续定位。

## 说明

- 正常阶段总结仍会保留联网知识拓展；只有首次结果不完整时才使用无联网回退。
- 自动回退会产生一次额外模型请求，但不会重复产生 Web Search 调用。
- 当前正在录制的旧版课堂不会被关闭或替换；新版在下次启动后生效。
