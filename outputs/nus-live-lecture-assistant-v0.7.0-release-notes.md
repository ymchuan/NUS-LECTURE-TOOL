# NUS 课堂同传 v0.7.0

## 模型配置优化

- 阿里云默认实时翻译升级为最低延迟档 `qwen-mt-lite`，并直接使用英译中、课程领域和术语映射参数。
- 实时翻译可选择 `qwen-mt-flash` 术语质量档，或 `qwen3.7-flash` 高并发低成本档。
- 阶段总结与整课总结改为独立模型设置，不再被迫共用同一档模型。
- 推荐组合为 `qwen3.7-flash` 阶段总结和 `qwen3.7-plus` 整课总结。
- 整课总结新增 `qwen3.7-flash` 经济档与 `qwen3.8-max` 深度档。
- 旧版阿里 `qwen3.5-flash` 默认设置首次启动时自动升级；用户之后的自定义选择会保留。

## 调用优化

- 自动总结、立即总结继续使用阶段模型，结束课堂生成整课总结时自动使用整课模型。
- 整课总结最大输出由 4000 Token 提升到 6000 Token，适合更完整的知识点、思维导图和拓展资料。
- 总结请求复用共享 HTTPS 连接，减少重复握手。

## 推荐课堂配置

```text
ASR       qwen-audio-3.0-asr-flash-streaming
翻译      qwen-mt-lite
阶段总结  qwen3.7-flash
整课总结  qwen3.7-plus
```

API Key 与区域规则不变：以上阿里模型均使用新加坡区域百炼 API Key。
