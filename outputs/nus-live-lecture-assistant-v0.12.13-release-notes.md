# NUS 课堂同传 v0.12.13

## 本次更新

- “实时英文转写”新增 Deepgram 供应商，默认选 Nova-3，可切换到 Nova-2。
- Deepgram 独立 API Key 支持保存、替换、删除和状态显示，使用系统凭据库，不要求 `sk-` 前缀。
- 新增 Rust 后端 WebSocket 连接，按英语、16 kHz、单声道 PCM 音频进行流式转写。
- 临时英文结果即时显示；多个已定稿片段在断句后合并提交，避免片段被重复翻译。
- 支持 400 ms 静音断句、UtteranceEnd、静音 KeepAlive 和暂停/结束时的转写收尾。
- Nova-3 可接收课程热词提示，实时记录区显示首字延迟。
- 设置中新增 Deepgram“测试连接”：发送约 0.5 秒的内存静音 WAV，检查 API Key、账户额度和所选 Nova 模型的 HTTPS 预录接口可用性。
- 已有 OpenAI 和阿里云转写选择继续保留，Deepgram 模型选择可独立保存。
- 中文翻译、阶段总结、整课总结和 AI 问答仍使用原有的 OpenAI 或阿里云文本供应商。

## 配置方式

1. 打开设置，在“实时英文转写”中选择 Deepgram。
2. 选择 Nova-3 或 Nova-2，填写 Deepgram API Key 并保存。随后可点击“测试连接”检查密钥、额度和模型可用性。
3. 在“翻译与总结模型”中保留或选择文本供应商，并确保该供应商的密钥已保存。
4. 开始课堂并允许麦克风权限。

API Key 不包含在源码、配置示例或发布说明中。曾在聊天、截图、日志或其他公开位置出现过的旧密钥必须立即在 Deepgram 控制台撤销并重新生成；新密钥不要再次发送到聊天中，只通过应用设置保存到系统 Keychain。原项目目录保留，新版本开发目录为 `/Users/zhengyi/Documents/ChatGPT/课堂同传`。
