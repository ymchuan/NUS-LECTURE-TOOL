# NUS 课堂同传 v0.12.7

## 本次更新

- 为 CEG5104 Cellular Networks 加入 123 个课程推荐术语，其中 49 个高优先级词覆盖 Singtel、StarHub、M1、SIMBA、IMDA、网络架构缩写、无线接入、话务工程和排队论。
- CEG5104 词表为空时首次打开会自动写入推荐词；已有词表不会被覆盖，也可在设置中点击“补充推荐词表”合并缺失项。
- 专业词表增加即时搜索，支持按英文、中文和别名查找。
- Qwen Audio 3 Streaming 使用带权重即时热词：高、中、低优先级分别对应 5、4、2；不再只取前 50 个词，最多可发送 2,000 个有效热词。
- 最重要的短专名和缩写同时写入 Qwen 识别上下文，进一步强化产品名、运营商名和技术缩写。
- PDF/PPTX 课件热词改为保留原始标题短语，并额外提取 BTS、MSC、GGSN 等大写缩写，不再使用用于页面匹配的词干结果。
- OpenAI 实时转写会在提示文本中明确列出课程词汇。
- Keychain 状态检查移至后台，升级后即使 macOS 请求重新授权，也不会阻塞应用主界面和课程数据加载。

## 使用方式

1. 打开“设置”，选择 CEG5104 Cellular Networks。
2. 在“专业词表与 ASR 热词”中搜索或编辑术语；高优先级适合经常误识别且不易与普通词混淆的专名。
3. 使用当前的阿里云新加坡 `qwen-audio-3.0-asr-flash-streaming` 开始下一节课堂，热词会在新识别会话启动时生效。

Paraformer Realtime v2 需要阿里云预编译热词列表 ID；本版本的即时加权热词优化针对当前使用的 Qwen Audio 3 Streaming。翻译与总结仍会使用同一门课的中英术语表。
