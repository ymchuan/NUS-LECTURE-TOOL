# NUS 课堂同传 v0.2.0

## 本次完成

- 使用 SQLite 保存课程、术语、课堂、英文转写、中文翻译和阶段总结。
- 支持创建、编辑和快速切换课程。
- 支持逐条维护中英术语、别名、优先级和启用状态。
- 已启用术语同时进入英文识别关键词和中文翻译词表。
- 录制期间按固定节奏自动保存，暂停和结束时立即保存。
- 应用意外退出后，启动时恢复未结束课堂的时长、语段和总结。
- 恢复后可继续录制，也可结束原记录并开始新课堂。

## 已验证

- macOS 桌面应用成功启动并显示新版课程管理界面。
- 课程与术语写入 SQLite 后，应用重启可完整读回。
- 临时未结束课堂在重启后正确恢复时长和中英语段。
- 前端 4 个测试与 Rust/SQLite 2 个测试通过。
- TypeScript 生产构建和 Tauri macOS release 构建通过。
