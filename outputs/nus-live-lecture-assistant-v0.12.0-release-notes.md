# NUS 课堂同传 v0.12.0

## 实时阅读体验

- 用户停留在转写底部时自动跟随最新内容；向上回顾后停止强制滚动。
- 离开底部后显示“回到最新”与未读语段数量。
- 添加标记现在会保存时间、对应语段和可编辑备注，并支持跳转与删除。

## 多周课堂与历史

- 一门课程可保存任意多节课堂，历史列表按日期展示转写、总结、标记和 Slides 数量。
- 已结束课堂可重新打开，完整英文、中文、阶段总结和整课总结继续保存在本地 SQLite。
- 历史课堂仍可使用 AI 问答。

## Slides 与 Syllabus

- 新课堂开始前可上传 PDF 或 PPTX Slides；文件和页级文本均保存在本机。
- Slides 标题自动加入实时 ASR 热词，并根据最近课堂内容自动匹配当前页。
- Syllabus 改为课程设置中的纯文本粘贴区，不需要上传文件。

## AI 问答与引用

- 支持“本节课”和“本课程”两种范围，课程范围可比较不同教学周。
- 可选择联网核验；课堂、Slides、Syllabus 和网页引用均可点击查看。
- 本地引用必须对应真实语段或页面，网页引用必须来自搜索工具返回结果。
- 对话、回答、引用和模型信息随课程持久化保存。

## 导出与备份

- 历史课堂可导出 Markdown。
- 全量备份包含数据库、课程、所有课堂、聊天和 Slides 文件。
- 备份恢复会先验证数据库结构，并在下次启动时应用，同时保留恢复前数据库副本。
