# NUS 课堂同传 v0.12.4

## 阶段总结

- 定位为课堂中的快速回顾，帮助补上刚才走神或没有听懂的小主题。
- 完整覆盖本阶段的开头与结尾，不再固定只读取最后 40 条转写。
- 使用 3-5 条关键结论和 2-6 个重点解释，保持适合 1-2 分钟阅读的长度。

## 整课总结

- 定位为课后可独立使用的详细复习资料，不再与阶段总结共用内容上限。
- 按时间顺序整合所有阶段的完整知识点、课堂依据、定义、例子和考试提示，并通过全程转写时间轴补漏。
- 正常完整课程要求 8-16 条整课主线、10-24 个详细知识点，以及更完整的术语、例子、复习问题和思维导图。
- 输出空间由 6,000 Token 提升至 14,000 Token；短课会自动降低最低条目数，避免凑数。

## 展示与导出

- 详情页分别标记“本段回顾”和“整课复习资料”，整课页显示覆盖数量和完整知识主线。
- 历史课堂的整课详情新增“重新生成”，仅在用户主动点击时按新版策略覆盖旧整课总结。
- Markdown 导出现在保留详细知识点、课堂依据、定义、例子、提示、问题和思维导图。
