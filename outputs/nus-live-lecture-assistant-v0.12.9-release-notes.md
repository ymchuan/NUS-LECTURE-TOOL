# NUS 课堂同传 v0.12.9

## 本次更新

- 新增阿里云新加坡 `qwen3-asr-flash-realtime`，并作为重口音与复杂教室环境的推荐识别模型。
- Qwen3 ASR 固定使用英文识别，避免课堂中的中文串音改变语言判断。
- 将断句静音阈值从 300 ms 调整为 800 ms，减少重口音、自然停顿和远距离收音导致的碎句。
- 把当前课程术语与导入课件提取的关键词作为 Qwen3 ASR 课堂上下文发送。
- 忽略明显以中日韩文字为主的最终识别片段，避免邻座中文谈话进入英文课堂记录。
- 新增 CEG5301 Machine Learning with Applications 推荐词表，覆盖课程 syllabus、神经网络、监督学习、强化学习和常见模型术语。
- 设置中新增课堂麦克风选择，可指定外接定向麦克风以改善老师声音与环境噪声的信噪比。
- 旧版选择阿里 Qwen Audio 3 的用户会自动迁移到 Qwen3 ASR；仍可手动切回 Qwen Audio 3 或 Paraformer。
