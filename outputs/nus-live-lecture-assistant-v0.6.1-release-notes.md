# NUS 课堂同传 v0.6.1

## 修复

- 修复阿里云中文翻译遇到一次临时网络抖动就立即失败的问题。
- 翻译请求复用 HTTPS 连接和 TLS 会话，减少每句话重新连接的延迟与失败概率。
- DNS、连接、TLS 或发送超时会以 200 ms、600 ms 间隔自动重试两次。
- 重试仍失败时，错误提示会区分连接超时、网络连接失败、请求发送失败和响应读取失败，并显示底层原因。

## 排查结果

- 英文实时 ASR 正常，截图中的首字延迟为 0.6 秒。
- 阿里云新加坡翻译端点地址正确；排查时 DNS、TCP 与 TLS 均成功，端点响应约 0.05 至 0.11 秒。
- 原报错发生在收到 HTTP 响应之前，因此不是模型名称、余额、配额或 API Key 校验错误，更符合瞬时网络连接失败。
